# Audiana
A lightweight, terminal-based audio player and analyzer designed for quickly inspecting and working with audio files.
## Requirements
- Java 21 or later
- Maven
# Setup Guide
1. To set up the project, open a terminal in your Audiana project directory and type: `mvn package`
2. To run the application, use the same project directory in the terminal and enter: `java -jar target/Audiana.jar`
3. To set your music folder directory, enter: `D`
 into the Audiana terminal, then paste the path.
4. Enjoy!
